# 🧠 Portafolio Backend - Andrés Camilo Solano Pantoja

Bienvenido a mi portafolio de desarrollo backend. Este proyecto fue construido con **React**, **Tailwind CSS**, y una estética inspirada en la conexión entre tecnología, naturaleza y tranquilidad. Aquí muestro quién soy como desarrollador: técnico, creativo y con visión de arquitectura limpia.

---

## 🚀 Tecnologías principales

- ⚛️ **React** – Librería moderna para interfaces de usuario
- 💨 **Tailwind CSS** – Estilizado rápido y responsive con clases utilitarias
- 🌀 **Framer Motion** – Animaciones suaves y naturales
- 🎨 **Estética Cyber-Nature** – Inspirada en naturaleza + ciberespacio
- 💬 **FormSubmit** – Envío de formularios sin backend
- 🌐 **Vercel** – Despliegue rápido y gratuito

## 📁 Estructura del proyecto

```
/public
  /assets         → Imágenes, íconos y logos
/src
  /components     → Secciones como Navbar, About, Contact, Projects
  /data           → Información estática
  App.tsx         → Entrada principal
  index.tsx       → Render de React
  main.tsx        → Setup general
```
